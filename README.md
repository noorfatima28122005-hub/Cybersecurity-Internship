# Cybersecurity-Internship

This repository contains the work completed during the Cybersecurity and Web Development internship at DevelopersHub Corporation.

## Week 4: Security Implementation
In this week, I implemented essential security measures to harden the web application:

- **Helmet**: Added to secure HTTP headers.
- **CORS**: Configured to manage cross-origin resource sharing securely.
- **Rate Limiting**: Implemented to protect the API against brute-force attacks and abuse.

This project focuses on enhancing API security and threat detection.
